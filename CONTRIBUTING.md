# Contributing to spine-leaf

Thanks for your interest in improving spine-leaf! Contributions of all sizes are welcome.

## Getting started
1. Fork this repository and clone your fork.
2. Create a branch: `git checkout -b my-change`.
3. Make your change, keeping it focused on one thing.

## Before you open a pull request
- Make sure the project still builds and existing tests pass.
- Add or update tests for behavior you changed, when applicable.
- Update the README/docs if you changed anything user-facing.
- Write a clear PR description: what changed, why, and how you tested it.

## Reporting bugs
Open an issue using the bug report template — include steps to reproduce, expected vs actual behavior, and your environment.

## Code of conduct
Be kind and constructive. See CODE_OF_CONDUCT.md.
